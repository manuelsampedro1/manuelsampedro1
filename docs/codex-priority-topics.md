# Codex Priority Topics

Use this list when choosing what to publish next. Pick topics that directly improve day-to-day work in Codex before broader AI trend content.

## Highest Leverage

- Follow-up notes that deepen `codex-review-packet`, `verify-by-change`, or `briefboard-local`.
- Repo review prompts that produce sharp findings instead of summaries.
- Debugging checklists for repeated failure patterns in local repos.
- Verification patterns: what to run after docs-only, script, frontend, or backend changes.
- AGENTS.md patterns that improve repo behavior without adding process bloat.
- Automation memory patterns that help recurring threads build on prior work.

## Strong Follow-Ups

- Small shell helpers for index refresh, artifact checks, or repo hygiene.
- Prompt templates for turning a real Codex session into a reusable recipe.
- Notes on when to stop asking questions and make a pragmatic assumption.
- Guardrails for avoiding empty commits, fake activity, and unverifiable claims.
- Patterns for keeping profile work aligned with actual client or product work.

## Lower Priority

- Broad AI tool commentary without a tested workflow.
- Generic productivity advice.
- Radar notes without a clear takeaway for Codex users.
- Maintenance-only diffs unless they unlock discoverability of better content.
- New profile artifacts that cannot link back to owned repos or real work.
