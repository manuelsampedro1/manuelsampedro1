# 2026-05-21 - AI Coding Profile Start

## Signal

A strong GitHub profile for AI builders should show repeated useful artifacts, not only pinned repositories or auto-generated metrics.

## Practical Takeaway

Use the profile repo as a stable front door and keep daily work in structured folders. This keeps the profile readable while still showing active work.

## Watchlist

- Codex workflows for repo changes, reviews, and automation.
- Claude Code workflows for local codebase execution.
- Agent evaluation patterns that can be reused across products.
