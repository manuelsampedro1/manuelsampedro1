# 2026-06-02 - Agent Run Ledger Checklist Import

## Context

`verify-by-change` can produce a change-aware verification checklist, and `agent-run-ledger` can store command evidence for an agent run. The missing link was operational: a reviewer still had to copy checklist sections into ledger events by hand.

That manual step is exactly where agent closeouts get soft. If the verification plan is generated by one tool and the run audit is kept by another, the bridge should be explicit and testable.

## Change

- Added `agent-run-ledger import-checklist --ledger <path> --checklist <path>`.
- Parsed `##` checklist sections into planned `command` events.
- Preserved section titles, backtick-only file bullets, and verification command bullets.
- Defaulted imported command evidence to `status: "planned"` while allowing `--status`.
- Added unit coverage for checklist parsing and CLI import behavior.
- Updated README usage examples with a `verify-by-change` to `agent-run-ledger` flow.

Public commit: `46de281c62f0 feat: import verification checklists`.
