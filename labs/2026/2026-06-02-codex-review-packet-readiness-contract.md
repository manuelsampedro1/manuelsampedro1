# 2026-06-02 - Codex Review Packet Readiness Contract

## Context

`repo-flightcheck` can now emit a compact `repo-flightcheck.agent-contract.v1` artifact, and `agent-run-ledger` can import that contract as blocker evidence. `codex-review-packet` still only rendered the older full `repo-flightcheck --json` report shape.

That left a gap in the review handoff: a reviewer could generate a readiness contract, but the packet would not render ready state, threshold, required blockers, or recommendations.

## Change

- Detected `repo-flightcheck.agent-contract.v1` inside `--readiness-report`.
- Rendered contract metadata: ready state, score, threshold, stack, required blockers, recommendations, and critical failures.
- Split `requiredBeforeAgent` and `recommendedBeforeAgent` into separate Markdown sections.
- Preserved the existing full readiness report renderer.
- Added tests for blocked and clean readiness contracts.
- Updated README examples to show both `repo-flightcheck --json` and `repo-flightcheck --contract`.

Public commit: `a8e50c8467c4 feat: render readiness contracts`.
