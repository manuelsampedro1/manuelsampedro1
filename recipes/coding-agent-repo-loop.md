# Coding Agent Repo Loop

Use this loop for Codex, Claude Code, or any repo-aware coding agent.

## Loop

1. Read the repo before choosing architecture.
2. Name the smallest useful outcome.
3. Identify files likely to change and files that should stay untouched.
4. Make the smallest coherent edit.
5. Run the closest available verification.
6. Document decisions only when they affect future work.
7. Report what changed, what was verified, and what remains blocked.

## Anti-Patterns

- Starting with a new abstraction before reading local patterns.
- Creating daily commits that only modify timestamps.
- Using generated content as if it were tested product evidence.
- Adding dependencies to avoid a small amount of product thinking.
